# Competition logo sources

These local assets are used for the FantasyUefa fan-made interface and are not presented as sponsorship or endorsement.

- `premier-league.svg` — downloaded from the Premier League logo site: https://logo.premierleague.com/
- `laliga.png` — downloaded from LaLiga's official pressroom logo downloads: https://www.laliga.com/en-GB/pressroom/logos-and-corporate-dossier/logos
- `champions-league.png` — converted to a web-friendly PNG from UEFA's official media download package: https://www.uefa.com/news-media/mediaservices/mediadownloads/

Brand ownership and usage remain with the respective rights holders. The site footer continues to identify FantasyUefa as an unofficial fan-made concept.
